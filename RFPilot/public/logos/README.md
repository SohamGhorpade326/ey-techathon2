# Logo Files

Please place the following logo files in this directory:

1. **tenders-maharashtra.png** - Tenders Maharashtra logo (orange circular logo)
2. **gem-portal.png** - GeM Government e-Marketplace logo (colorful star with GeM text)
3. **nhai.png** - National Highway Authority of India logo (blue and yellow highways logo)
4. **wbsedcl.png** - West Bengal State Electricity Distribution Company logo (blue electricity tower logo)
5. **ireps.png** - Indian Railways IREPS logo (Indian Railways emblem with IREPS text)

All logos should be:
- PNG format with transparent background
- Max height: 40-50px
- Optimized for web use

The logos will be displayed in a grayscale format by default and will show full color on hover.
